# Lingzhi Antifungal Patch Research

## Project Overview
This repository documents the research and development plan for a Lingzhi (*Ganoderma lucidum*) extract-based biomaterial patch intended for topical antifungal applications.

## Research Objectives
- Review scientific literature on *Ganoderma lucidum* and its potential antifungal properties.
- Explore biomaterial patch formulations and their suitability for topical applications.
- Document the research methodology, project progress, and findings when available.

## Repository Contents
- `manuscript/` — Research manuscript drafts.
- `references/` — Literature review and reference list.
- `methodology/` — Research design and planned methods.
- `project-planning/` — Timeline and task responsibilities.

## Research Status
Project planning and literature review. Experimental results will be added only when available.

## Note
This repository is for research documentation. The proposed patch's safety and antifungal efficacy have not been established unless supported by completed experiments.
